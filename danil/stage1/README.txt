Автопроверки заданий этапа 1 (Данил)

1. Распакуй эту папку в свой репозиторий, например в danil/stage1/.
2. Решение каждого задания сохраняй в этой же папке под именем из задания:
   task_2_1.py, task_2_2.py, task_2_4.py, task_3_2.py, task_3_3.py,
   task_4_1.py, task_4_2.py, task_5_2.py, task_5_3.py
3. Запуск проверки из этой папки, с активным окружением .venv:
   python check_2_1.py
4. [+] — случай прошёл, [-] — нет. Под строкой с [-] иногда есть подсказка.

Файл _common.py — общая часть всех проверок, его не нужно менять или запускать.
Готовых решений здесь нет, только ожидаемые ответы.
Подробнее — в справочнике, раздел 1.7.
